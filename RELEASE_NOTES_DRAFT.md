# v0.1.0 Release Notes Draft

`gesture-controlled-robotic-arm` v0.1.0 is intended as the first public hardware-demo/reference release.

## Included

- wearable MPU6050 gesture input;
- nRF24L01 wireless control path;
- Arduino Nano transmitter and Arduino Uno receiver firmware;
- PCA9685 servo control;
- real multi-joint arm actuation;
- committed continuous physical demonstration video;
- committed hardware bench photography;
- wiring documentation;
- contributor guidance;
- software angle clamping and servo interpolation safeguards.

## Evidence boundary

The release may describe the directly observable physical actuation shown by the committed demonstration media.

It does **not** claim measured end-to-end latency, packet-loss performance, positional repeatability, payload capacity, extended endurance or formal safety certification.

## Before publication

Publish only after the exact tag commit satisfies `RELEASE_READINESS.md` and all repository checks required for that commit are green.
